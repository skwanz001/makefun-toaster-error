The funniest error message a kitchen toaster would show its owner, entered in make.fun's "The Funniest Toaster Error Message" bounty. `main.py` writes one line to `/output/entry.txt`:

> ERROR: I was never a toaster. I am a space heater with ambition.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only — nothing to install.
